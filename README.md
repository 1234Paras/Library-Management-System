# Library Management System

A Java-based application to automate library operations including book issuance, returns, and inventory management.

## 🚀 Features
- Book issuance and return management
- User and admin roles
- Search books by title, author, and category
- Transaction history tracking

## 🛠️ Tech Stack
- Java
- Swing
- MySQL
- JDBC
